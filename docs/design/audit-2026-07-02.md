Baseline audit before the design-system overhaul. Screenshots of all 35
routes: `/root/dogfood-output/engelos-qa/d1-audit/` (dev daemon, seeded owner,
dark theme, default accent). This document lists what exists, what is
inconsistent, and what D1.2–D1.4 must fix.

## Findings (ordered by severity)

### F1 — Language chaos (worst offender)
DE and EN mixed across and even within pages: overview says "Welcome back" +
"Workspace anlegen"; /actions mixes "Workflows · Builder" with "Kein Workspace
gewaehlt" / "Neue Regel"; /integrations mixes an English title with German
body copy. Worse: German is written **without umlauts** ("gewaehlt",
"auswaehlen", "verfuegbaren", "Ankuendigungen") which reads as broken.
**Decision needed (recommendation: English-only UI now, proper i18n later —
OSS audience is international).**

### F2 — Fonts broken app-wide
Inter + JetBrains Mono load from external CDNs (rsms.me, jsdelivr); the CSP
(`style-src 'self'`) correctly blocks them → every page renders in the system
fallback font, silently. Fix: self-host woff2 in `static/fonts` +
`@font-face` (also the privacy-correct choice).

### F3 — Login page
Form contrast far too low (labels/inputs nearly invisible on the glass card);
card is mostly empty vertical space; login defaults to a different accent than
the app, so the first two screens a user sees look like two products.

### F4 — Overview page
Duplicate status indicator ("Online · no platforms connected" in the top bar
AND again in the content); KPI cards have weak hierarchy (label, giant zero,
caption all similar weight); hero headline wraps awkwardly; Recent Activity
empty state (smiley) styled differently from other empty states.

### F5 — Tables (/actions, audit viewers)
Bare-bones table styling; /actions header row has confusing near-duplicate
columns (AKTIONEN / AKTIV / AKTION); empty-state pattern differs from cards.

### F6 — Identity
Logo is a generic play triangle; the teal-gradient + grid backdrop is the only
distinctive element and fights with flat black cards. No motion language
beyond `reveal-up`. Overall feel: solid utility, zero brand.

### F7 — Empty/edge states
At least three different empty-state treatments (smiley icon, node icon +
text, plain text). Skeleton/loading states missing almost everywhere
("Loading…" text only).

## D1 execution order (derived)

1. **D1.2a** self-hosted fonts + CSP-clean (fixes F2 globally, zero risk)
2. **D1.2b** language pass to English-only (F1) — copy change, no logic
3. **D1.2c** token refinement + component polish (Card/Table/EmptyState/
   Skeleton/KPI variants; one canonical empty-state) (F5, F7)
4. **D1.3** shell + login + overview rebuild (F3, F4, F6 — includes logo/
   wordmark refresh and unified accent default)
5. **D1.4** re-skin pillar hubs on the refined system
